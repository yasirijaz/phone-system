# **App Name**: CallSync

## Core Features:

- Call Log: Display a call log with details like contact, time, and duration.
- Call Filtering: Allow filtering calls by contact or date range.
- Manual Call Entry: Provide the ability to create manual call logs with notes and categorization.
- AI Call Categorization: Use generative AI as a tool to automatically categorize calls (e.g., sales, support, personal) based on notes entered, or conversation summary if available.
- Call Statistics: Display summarized statistics on calling behavior, like calls per day/week, most frequent contacts, or categorized call time.

## Style Guidelines:

- Primary color: Light blue (#7BB5C9) for a professional and calm feel, suggesting reliability.
- Background color: Very light blue (#F0F8FF) providing a clean and unobtrusive backdrop.
- Accent color: Darker blue (#336B87) to draw attention to key UI elements such as action buttons and selected filters.
- Body and headline font: 'Inter', a sans-serif font, known for its readability and modern appearance; suited for both headlines and body text.
- Use simple, outline-style icons to represent call types, contacts, and filtering options.
- Employ a clean, card-based layout to present call logs and summaries, ensuring information is well-organized and easily digestible.
- Use subtle transition animations when filtering calls or opening detailed call views for a smooth user experience.
